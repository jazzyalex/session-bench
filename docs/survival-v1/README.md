# Session-Bench v1.0 evidence contract

This directory defines the deeper evidence layer for the v1.0 evolution of the
historical v0.4 vendor report card. One OpenCode configuration has local Session Survival
records whose successor correction packages now replay from their own bytes; there is no
full v1.0 vendor score or cross-product ranking.
Nothing here changes the v0.4 rubric, data, or report.

- [Protocol](protocol.md): five surface identities, one workload, independent observation,
  native capture, and calibration gates.
- [Rubric](rubric.md): one `/100` score built from 19 deep Session Survival metrics and 12
  broad format metrics.
- [Static surface preflight](surface-preflight.md): installed-build and capture-route
  notes; these are not results.
- [Discrimination pre-test](discrimination-pretest.md): structural observations from
  older synthetic pilots; these receive no v1.0 score.
- [Attempt ledger](attempt-ledger.md): retained campaign schedule and attempt states.
- [Calibration snapshot](calibration-status.md): what the five live surface attempts
  proved, why no vendor score exists yet, and the exact next gates.
- [Preliminary report](preliminary-report.md): the five-surface reader-facing result,
  bounded OpenCode finding, release-cohort blockers, and practical interpretation.
- [Finish plan](../../plans/survival-v1/finish-v1-execution-plan.md): the ordered path
  from local evidence corrections through independent reproduction and a reviewable
  release candidate.
- [OpenCode correction contract](reproducibility-correction.md): the closed-runtime and
  sanitization requirements before the retained local records can be replayed or shared.
- [Prospective release campaign](../../plans/survival-v1/campaign-prospective-claude-cohort.json):
  frozen Codex/Claude/OpenCode release-cohort identities, workload digests, and gates.
- [Historical Cursor campaign](../../plans/survival-v1/campaign.json): retained attempts,
  build identities, workload digests, authorization, and quota stop.
- [Claude Code adapter](adapters/claude-code.md): declared copied-JSONL decoder boundary
  and separate CLI/Desktop calibration blockers.
- [Codex CLI adapter](adapters/codex-cli.md): isolated-session controller, exact resume
  contract, and current invalid/N/A calibration records.
- `adapters/`: remaining per-surface acquisition contracts and current calibration blockers.
- [Public-data policy](public-data-policy.md): privacy, provenance, citable outputs, and
  correction rules.

The intended public result keeps v0.4's compact leaderboard, five category bars, vendor
report cards, gate matrix, **To pass, fix** guidance, and **If you're building on session
files** table. V1.0 adds separate CLI and Desktop rows, three-run ranges, verification
badges, an observed-vs-recorded timeline, immutable native evidence, and generated
use-case recommendations.

The fixed public categories are:

| Category | Points |
|---|---:|
| Record fidelity | 30 |
| Causality & context | 20 |
| Usage & attribution | 15 |
| Portability & openness | 20 |
| Durability & signal | 15 |

The executable workload lives under `fixtures/scenarios/survival-v1/workload/`. Existing
prototype decoders and scorers are calibration foundations only. They do not establish a
v1.0 result until the complete 31-metric evidence wrapper, broad format probes, copied-root
reproduction, badge rules, and recommendation rules are implemented and satisfied.

Crash qualification is a separate, unscored diagnostic. A crash result never adds or
removes leaderboard points or controls the edition name.
