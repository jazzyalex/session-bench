Status: active implementation, 2026-09-29. Owner instruction: release v1 as soon
as practical with all ten v0.4 harnesses, Codex/Claude/Cursor desktop, and
DeepSeek Harness CLI (`dsh`). Luna and Sol delegation and Oracle Sol Pro review
are authorized. This reopens the scope frozen in the September 15 finish plan;
the earlier plan and captured artifacts remain historical evidence.

## Release population

The executable manifest is `registries/v1-release-scope.json`. It preserves
the ten historical identities and defines 14 separate configuration rows:
Pi, OpenClaw, Claude Code CLI, Codex CLI, Kimi Code, OpenCode CLI, Hermes,
Copilot CLI, Antigravity, Cursor CLI, Codex Desktop, Claude Desktop Code
(Local), Cursor Desktop, and DeepSeek Harness CLI.

Every row remains visible. An incomplete or unavailable configuration receives
a reason, never an invented zero or a carried-forward v0.4 score. All 14 belong
to the release scope; a per-row status is distinct from rank eligibility. The
owner's requested full-coverage release is not complete merely because the
report generator can display 14 names.
